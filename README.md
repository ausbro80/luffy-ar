# 🏴‍☠️ 루피 고무고무 피스톨 AR 🥊

> 카메라 앞에서 주먹을 쥐면 루피가 고무고무 피스톨을 발사해요!

## 🎂 5월 5일 = 루피 생일!

원피스 주인공 몽키 D. 루피의 생일을 기념해서 만든 AR 앱이에요.

## 🎯 사용법

1. START 버튼 클릭
2. 카메라 권한 허용
3. ✋ 손을 카메라 앞에 보여주기
4. ✊ 주먹 쥐기!
5. 루피가 **고무고무 피스톨!!** 발사 🥊

## 🛠️ 기술 스택

- **Three.js** - 3D 렌더링
- **MediaPipe Hands** - 손가락 추적 (Google)
- **WebGL** - 카메라 + 3D 합성
- **GitHub Pages** - 호스팅

## 📂 구조

```
luffy-ar/
├── index.html         # 메인 앱
└── assets/
    └── luffy.glb      # 루피 3D 모델
```
